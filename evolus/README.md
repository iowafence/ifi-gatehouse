# evolus

**Status: the client (`tools/evolus_client.py`) is not wired into the demo.** `AGENT_INSTRUCTIONS.md` is the instruction text for an Evolus estimating agent (it may only call the engine; it never calculates). `tools/evolus_client.py` is a small REST client with a mock mode (`EVOLUS_MOCK=1`) used by the tests. The live Bid Desk uses a separate server-side connector (`web/lib/evolus-desk.ts`), switched on only by `EVOLUS_DESK_ENABLED=1`; nothing in this directory is called by the demo. Separately, an Evolus adapter outside this directory ran two real workflow executions on 2026-10-14; their stored traces and review cases are in `release_evidence/` and are displayed read-only by the AI Flight Recorder. Credentials come from environment variables only.
