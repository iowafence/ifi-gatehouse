# samples/public-demo

Reviewed public **synthetic** assets, each listed with its SHA-256 and provenance in [`../public-assets.sha256`](../public-assets.sha256) (enforced by `scripts/check_secrets.sh`).

| Path | What it is |
|---|---|
| `dp001/` | The fictional DP-001 bid package: two drawing sets (17x11 and the original 34x22), Addendum 01, Project Manual and Instructions to Bidders. Generated by IFI Labs, watermarked fictional, no real owner or site. |
| `reference_pricing_workbook_v2_3_0.fictional.xlsx` | Fictional reference rate workbook used by the pricing engine. Every rate is an invented demonstration value. |

Real customer or bid documents, answer keys and private rate books must never be placed here. The JSON scope fixture used by the generic demonstration is `../scope_synthetic.json`. The test-only three-crew workbook is generated, not stored: `python3 legacy_fixtures/build_legacy_testbook.py`.
